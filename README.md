# MLproject

# Titanic
### How to use
1) `pip install -r requirements`
2) `python main.py` для обучения и предсказаний MLP модели, результаты сохранятся в outputs, пути и параметры модели можно менять в **config.py** или **config.yaml,** если через **config.py**, то сначала запустить `python config.py`, он создаст yaml конфиг, который будет использоваться моделью. слои модели можно менять в **model.py**, результаты сохранятся в **outputs/**
3) `python compare.py` для запуска сравнения моделей sklearn, результаты выведутся в терминал и сохранятся в **outputs/**, предсказания бустингов сохранятся для ансамбля
4) `python ensemble.py` для получения предсказаний ансамблей
5) `python for_upload.py` для получения предсказаний какой-либо одной конкретной модели sklearn

> `data.py` содержит все преобразования данных, описанных в `eda.ipynb`

# House Prices
## How to use
1) `pip install -r requirements`
2) `python main.py` для обучения и предсказания MLP модели, результаты выведутся в терминал, конфиг и метрики сохранятся в **outputs/{имя эксперимента}** вместе с предиктами в **submission.csv**. Пути и параметры модели можно менять в **config.py** или **config.yaml,** если через **config.py**, то сначала запустить `python config.py`, он создаст yaml конфиг, который будет использоваться моделью. слои модели можно менять в **model.py**.
3) `python optim.py` для оптимизации параметров MLP модели с помощью Optuna. По умолчанию будут оптимизироваться *hidden_dims, dropout_rate, lr, weight_decay, batch_size*. Для оптимизации собственных параметров нужно будет самостоятельно внести правки в функции objective и main
4) `python not_nn_compare.py` для запуска сравнения моделей sklearn и бустингов, метрики выводятся в терминал, лучшая по метрике модель делает предсказания, которые записываются в `outputs/not_nn/submission.csv`
5) `python ensemble.py` для получения предсказаний ансамбля

> `data.py` содержит все преобразования данных, описанных в `eda.ipynb`

Финальный ансамбль был создан по туториалу из ноутбука:
`ensemble_pred = stacked_pred * 0.70 + xgb_pred * 0.15 + lgb_pred * 0.15`
а стекинг состоял из ElasticNet, GradientBoostingRegressor, KernelRidge  которые шли в метамодель Lasso. Но ключевой прирост в скоре дал именно улучшенный EDA, благодаря которому модели дали заметно лучшие результаты. MLP в данном соревновании показал худшие результаты, что, судя по другим ноутбукам, можно было ожидать. Сама модель была однослойная, при ее усложнении скор лишь ухудшался, возможно такой результат из-за малого размера датасета.
